# CodeAlpha_Movie_Analysis

This repository contains my submission for the Data Analytics Internship at CodeAlpha. The project focuses on executing both **Exploratory Data Analysis (EDA)** and **Data Visualization** on a movie insights dataset using Python.

## 📋 Tasks Completed
*   **Task 2: Exploratory Data Analysis (EDA)** - Investigated data structures, handled summary statistics, checked for missing values, and analyzed genre patterns.
*   **Task 3: Data Visualization** - Built clear visual charts using Matplotlib and Seaborn to communicate data insights effectively.

## 🛠️ Tech Stack & Dependencies
*   **Language:** Python
*   **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 📊 Key Insights Found
1. **Rating Distribution:** Explored how movie ratings peak across the dataset.
2. **Revenue vs Ratings:** Visualized the correlation between a movie's financial gross and its overall IMDb score across different genres.
